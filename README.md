# 🔐 수학 방탈출 — 동인고 지하에서

> 학교를 마치고 학원으로 가던 중, 뒤에서 **쿵!**
> 눈을 떠 보니 동인고 지하 소학실. 문은 모두 잠겨 있다.
> **50분 안에** 문제를 풀어 각 층의 방화문을 열고, 5층 학생 자율공간의 휴대폰으로 도움을 청해라.

수학 수업용 방탈출 웹앱입니다. 설치 프로그램 없이 **GitHub Pages**에 올려서 학생들은 크롬북·태블릿·휴대폰 브라우저로 접속합니다.

| | 학생 버전 (`student.html`) | 교사 버전 (`teacher.html`) |
|---|---|---|
| 로그인 | 선생님 코드 + 학번 + 자유 이름 + 난이도(중/상) | 아이디 + 비밀번호 (선생님마다 따로) |
| 하는 일 | 인트로 스토리 → 지하~4층 방화문 5개 열기 → 5층 휴대폰으로 112 신고 | PDF/이미지에서 문제 영역을 잘라 등록, 정답·힌트 입력 / 실시간 현황판 |
| 규칙 | **중**: 문 하나에 자물쇠(문제) 2개 · **상**: 문 하나에 1개 | 게임 시작 버튼, 결과 CSV, 전체 초기화 |

---

## 1. 일단 내 컴퓨터에서 써 보기 (DEMO 모드, 5분)

`js/config.js`의 Firebase 칸이 비어 있으면 **DEMO 모드**로 작동합니다.
DEMO 모드는 **한 컴퓨터의 같은 브라우저 안에서만** 데이터가 공유됩니다(탭끼리). 테스트용이에요.

1. 폴더에서 간단한 웹서버를 켭니다. (그냥 html 더블클릭으로는 작동하지 않아요)
   - VS Code: 확장 **Live Server** 설치 → `index.html` 우클릭 → *Open with Live Server*
   - 또는 터미널에서: `python -m http.server 8000` → 브라우저에서 `http://localhost:8000`
2. **교사** 탭: 아이디 아무거나(예: `test`) + 비밀번호 `1234` → 문제 만들기 → PDF 올리고 드래그해서 문제 등록
3. **학생** 탭(새 탭): 학번 입력 → 대기 화면 → 교사 탭에서 **게임 시작하기** 클릭 → 인트로 시작

---

## 2. 실제 수업용: Firebase 연결하기 (무료, 약 15분, 한 번만)

학생 30명이 각자 기기로 접속하고 교사가 실시간으로 보려면 온라인 저장소가 필요합니다. Google **Firebase**의 무료(Spark) 요금제로 충분합니다.

1. <https://console.firebase.google.com> → **프로젝트 추가** (이름 예: `math-escape`) → Google 애널리틱스는 꺼도 됩니다.
2. 왼쪽 **빌드 › Firestore Database** → **데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → *프로덕션 모드*로 시작.
3. **규칙** 탭 → 이 저장소의 `firestore.rules` 내용을 통째로 붙여넣고 **게시**.
4. 왼쪽 **빌드 › Authentication** → 시작하기 → 로그인 방법에서
   - **익명(Anonymous)** 사용 설정 (학생용)
   - **이메일/비밀번호** 사용 설정 (교사용)
   - (교사 계정은 Firebase에서 만들 필요 없이, 사이트의 **선생님 등록**에서 각자 만듭니다)
     (진짜 메일 주소가 아니어도 됩니다. 예: `teacher@dongin.escape`)
5. 프로젝트 개요 옆 ⚙️ **프로젝트 설정** → 아래 *내 앱* → 웹 앱(`</>`) 추가 → 나오는 `firebaseConfig` 값들을 `js/config.js`의 `firebase: { ... }` 에 복사.
6. `js/config.js`의 `signupCode`(가입 코드)를 원하는 말로 바꾸고, 함께 쓸 선생님께만 알려 주세요.
7. Authentication › **설정 › 승인된 도메인**에 GitHub Pages 주소(`아이디.github.io`)를 추가합니다.

> 💡 Firebase의 `apiKey`는 비밀번호가 아니라 "어느 프로젝트인지" 알려 주는 값이라 GitHub에 공개돼도 괜찮습니다. 실제 보호는 3번의 **규칙**이 합니다. 각 선생님은 자기 방(선생님 코드)의 문제·기록만 고칠 수 있어요.

## 3. GitHub Pages에 올리기

1. GitHub에서 새 저장소 만들기 (예: `math-escape-room`, **Public**)
2. 이 폴더의 파일을 모두 업로드 (*Add file › Upload files* 로 드래그하면 됩니다)
3. 저장소 **Settings › Pages** → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save
4. 1~2분 뒤 주소가 나옵니다: `https://아이디.github.io/math-escape-room/`
   - 학생에게: 교사 화면의 **📱 학생 접속 QR** (선생님 코드가 들어간 `…/student.html?t=코드` 주소)
   - 교사: `…/teacher.html`

### Vercel로 배포하는 경우 (GitHub Pages 대신)

1. 위 1~2번처럼 GitHub 저장소에 파일을 올립니다.
2. <https://vercel.com> → GitHub 계정으로 로그인 → **Add New › Project** → 이 저장소 **Import**
3. 설정은 건드리지 말고(Framework Preset: *Other*) **Deploy**
4. 주소가 나옵니다: `https://math-escape-room-xxxx.vercel.app`
5. Firebase › Authentication › 설정 › **승인된 도메인**에 이 `…vercel.app` 주소를 추가
6. 이후 GitHub에 파일을 다시 올리면 Vercel이 자동으로 새로 배포합니다.

교사 페이지의 **📱 학생 접속 QR** 버튼을 누르면 학생용 주소가 큰 QR코드로 뜹니다. 프로젝터에 띄워 두면 됩니다.

## 4. 여러 선생님이 함께 쓰기

- 선생님마다 `teacher.html` → **처음이세요? 선생님 등록**에서 아이디·비밀번호를 만듭니다. (가입 코드 필요: `js/config.js`의 `signupCode`)
- **아이디 = 선생님 코드**입니다. 문제·정답·설정·학생 기록이 모두 그 코드의 방에만 저장되어, 다른 선생님 것은 보이지도 고쳐지지도 않습니다.
- 학생은 QR로 들어오면 선생님 코드가 자동으로 채워집니다. 주소로 들어오면 코드를 직접 입력합니다.
- 비밀번호를 잊은 선생님은 Firebase 콘솔 › Authentication › 사용자 에서 `아이디@dongin.escape` 줄의 ⋮ › 비밀번호 재설정.

## 5. 수업 운영 순서

1. **수업 전**: 교사 페이지 › 문제 만들기에서 문제 등록
   - 중: **10문제 이상**, 상: **5문제 이상** (더 많이 넣고 '섞기'를 켜면 옆 친구와 문제가 달라져요)
2. **수업 시작**: 교사 페이지 › 실시간 현황을 프로젝터에 띄우기 → 학생 로그인 (대기 화면에서 기다림)
3. 모두 들어오면 **🔒 게임 시작하기** → 학생 화면에서 인트로가 동시에 시작
4. 진행 중: 건물 단면도에서 누가 몇 층에 있는지, 오답·힌트 수, 접속 상태(초록 점)를 확인
5. 끝나면 **⬇ 결과 CSV** 저장 → 다음 반 수업 전 **전체 초기화**

- 학생이 새로고침하거나 기기를 바꿔도 같은 학번으로 다시 로그인하면 **이어서** 진행됩니다.
- 표의 ✕ 버튼으로 특정 학생 기록을 지우면 처음부터 다시 도전할 수 있어요.

## 6. 문제 파일 만들기 팁

- **한글(HWP)** 은 브라우저에서 열 수 없어서 **한글 › 파일 › PDF로 저장하기** 후 올리세요. 캡처 이미지(PNG/JPG)도 됩니다.
- 페이지 위에서 **드래그**해서 문제 하나만 잘라 등록합니다. 한 페이지에 문제가 하나면 *페이지 전체를 문제로*.
- **정답 형식**: 학생 입력은 공백·전각문자·①②를 자동 정리해서 비교합니다.
  - 여러 형태 허용: `1/2 | 0.5 | 2분의1` 처럼 `|` 로 구분
  - 객관식: `3 | ③`
  - 정답은 단답형(숫자, 짧은 식)으로 정할수록 원활합니다.
- **힌트**를 적어 두면 학생이 시간 감점(기본 2분)을 받고 볼 수 있어요.
- 문제 순서: '섞기'를 끄면 목록의 위에서부터 차례대로 지하 → 1층 → … 문에 배정되므로 쉬운 문제를 위에 두세요.

## 7. 바꿀 수 있는 것 (`js/config.js`)

- 학교 이름, 시작 장소(지하 소학실), 목표 장소, 신고 번호(112/119)
- 각 층 이름·장소·도착했을 때 나오는 스토리 문장
- 기본 제한 시간 / 힌트 감점 / 오답 잠금 시간 (교사 페이지 설정 탭에서도 변경 가능)

## 8. 참고 · 한계

- 정답은 원문 대신 **해시값**으로 학생에게 전달됩니다. 다만 숫자 정답은 컴퓨터를 잘 아는 학생이 마음먹으면 추측할 수 있으니, 성적 평가가 아닌 **수업 활동용**으로 쓰는 것을 권합니다.
- Firestore 무료 한도(하루 쓰기 2만 회)를 고려해 학생 접속 신호는 1분마다 보냅니다. 30명 × 50분 수업 기준 한 반에 약 2천~3천 회 정도라 하루 5~6개 반은 충분합니다.
- 문제 이미지는 Firestore에 압축(JPEG)해서 저장합니다. 문제 하나당 1MB를 넘을 수 없어 자동으로 화질을 조절합니다.
